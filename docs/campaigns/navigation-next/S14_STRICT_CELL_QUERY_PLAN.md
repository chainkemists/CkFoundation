## Verified basis and prerequisite

The published field already has sufficient ordinary cardinal topology once field format v2 is present. The v2 plate invariant requires every within-plate cardinal edge to be reciprocal and walkable. `CkGroundNav_Query_CellStep` is the canonical query-time reconstruction: `Get_StepAcross` resolves same-plate movement, exact local portal runs, seam portal runs, target layer, target surface Z, clearance, and admission. Bake-time portal extraction retains cross-layer crossings through the connection field before publication. Published fields intentionally retain no connection field or general neighbour table.

Do not rebuild this topology in the new search. Reuse `Get_StepAcross` for each of the four cardinal ordinary edges. `FCk_GroundNav_PathSearch` and `PlatePortalGraph` cannot be reused as the graph because their nodes are portal crossings and a same-plate query completes directly. `Query_SurfaceWalk` is a DDA ray/walk, not a detouring search. The new graph may reuse `CkAStar` state and `FCk_GroundNav_PathSliceParams`.

## Search and policy contract

For each cardinal transition, first call `Get_StepAcross`; then apply normal clearance, compiled query-filter denied plates, and the compiled per-plate cost multiplier. The processor already obtains those tables once from `Get_CompiledFilterTables` before search and must pass the same tables into the cell graph and its postprocess. Dynamic blockers are an additional hard veto, not a replacement for filter costs or denials.

The normal hard veto is the lead-approved conservative closed-cell rule at the existing baked resolution: reject a target when its closed horizontal cell square intersects a dynamic footprint and that target surface's actual Z lies within the footprint's finite vertical interval. Tangency counts as blocked. It can reject safe sub-cell slivers and makes no continuous-free-space completeness claim.

### Covered-start escape

The start exception is a monotonic dynamic-union state, not a one-cell exception. A radius-126 disc can cover many 25uu cells.

* If the original request start is clear, seed only the `Escaped` state; no blocked cell may be entered.
* If it is covered, seed `InsideInitialUnion`. The first segment is request start to the first surface centre; later segments join actual surface centres.
* While inside, an edge is legal only if the analytic union occupancy along the complete segment is one continuous interval beginning at `t=0`. If it covers the whole segment, remain inside. If it exits before segment end, the target must be clear and transition to `Escaped`. A gap or re-entry on that edge is rejected.
* Once escaped, every dynamically blocked target is rejected permanently.

Compute and merge exact disc/OBB segment intervals for this state. A raster connected component is insufficient because closed-cell expansion can falsely connect distinct shapes and permit escape through another obstacle. Ordinary escape edges are cardinal surface edges only; authored links are never an escape mechanism. Link destinations use normal post-escape blocker admission.

The stationary-disc snapshot uses the actual confirmed AreaMarkup box, not a new height: `[MarkupLocation.Z - MarkupVerticalHalfExtentUu, MarkupLocation.Z + MarkupVerticalHalfExtentUu]`. `CkCrowdAgent_StationaryMarkup_Processor.cpp:144-154` creates that box with vertical half extent `InParams.Get_Height()`, and :160-165 persists the same centre and extent in `FFragment_CrowdAgent_NavMarkup`; `CkCrowdAgent_Fragment.h:235-254` documents its floor coverage. `CkGroundNav_MarkupMask.cpp:417-460` already tests markup against each cell's actual surface Z. The snapshot collector must require a finite positive persisted extent and confirmed markup.

### Authored links

Build a per-search endpoint index over `Field._ResolvedLinks`. Mirror the plate graph's existing checks: resolved/enabled state, direction, link clearance admission, denied IDs, denied user-type tags, and link multipliers. A legal link is a predecessor edge with its metadata retained. Its destination must pass normal dynamic blocker admission; a blocked source may depart only under the cardinal covered-start escape rule, so no link gets implicit obstacle traversal permission.

## Scheduling and statuses

`CkGroundNavPath_Processor` owns the fair sliced execution. The cell search must consume the existing per-slice iteration cap and `_SliceRemainingThisTick`, account elapsed time there, and produce the same result for sliced and unlimited execution. It must not use `FCk_NavSurface_PathQuery::Try_FindPathSync` or any synchronous bypass.

An exhausted strict graph returns `Unreachable`, which maps to `FindPathNoPath` and triggers the existing one permissive retry. A search cap returns native `BudgetExceeded`, which maps to `ECk_Nav_PathFailReason::BudgetExceeded`. `OnPathResolved` retries only its explicit route-failure reasons and excludes `BudgetExceeded`; no retry-dispatch change is required if this mapping is preserved. Snapshot changes belong to a later request, never a running search. A field epoch change invalidates a cell-overlay path into a cold replan; it does not attempt plate-corridor repair.
