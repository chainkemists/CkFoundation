# CkEditorGraph

**Editor infrastructure module.** Base graph/schema for CkFoundation editor graphs — node bases and connection validation used by every `*Editor` module that shows a node canvas.

**Depends on:** `CkCore`, `CkLog`. No Ck deps beyond those.

For context on how this fits with the full editor module ecosystem, see [`/Source/EDITOR_MODULES.md`](/Source/EDITOR_MODULES.md).
