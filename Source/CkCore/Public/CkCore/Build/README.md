# CkCore / Build

Compile-time feature flags for CkCore. The macros defined here gate Ensure (`CK_DISABLE_ENSURE_CHECKS`, `CK_DISABLE_ENSURE_DEBUGGING`), debug (`CK_DISABLE_DEBUG_*`), and similar build-variant behavior.

**Key files:** `CkBuild_Macros.h`

For the full use-case table and how this folder fits with the rest of CkCore, see [`../../Claude.md`](../../Claude.md).
