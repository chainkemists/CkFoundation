# CkCore / Enums

Cross-module enums that don't fit anywhere else (`ECk_NormalizationPolicy`, engine-wide on/off/auto modes). Also the home of `CK_DEFINE_CUSTOM_FORMATTER_ENUM` for registering fmt-formatters on `UENUM` types.

**Key files:** `CkEnums.h`

For the full use-case table and how this folder fits with the rest of CkCore, see [`../../Claude.md`](../../Claude.md).
