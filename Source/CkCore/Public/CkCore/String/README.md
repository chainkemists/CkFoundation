# CkCore / String

`FString` / `FName` / `FText` helpers plus fuzzy matching for search UIs. Fuzzy match exposes `FCk_FuzzyMatch_Fragment_Data` for scored results.

**Key files:** `CkString_Utils.h`, `CkFuzzyMatch_Utils.h`, `CkFuzzyMatch_Fragment_Data.h`

For the full use-case table and how this folder fits with the rest of CkCore, see [`../../Claude.md`](../../Claude.md).
