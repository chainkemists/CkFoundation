# CkCore / Actor

Helpers for `AActor` — spawn, find, cast-with-validation, utility overloads. Use `UCk_Utils_Actor_UE` instead of re-rolling `GetWorld()->SpawnActor` / `Cast<>` + null-check patterns.

**Key files:** `CkActor.h`, `CkActor_Utils.h`

For the full use-case table and how this folder fits with the rest of CkCore, see [`../../Claude.md`](../../Claude.md).
