# CkCore / Settings

`UCk_Core_Settings` — project settings for CkCore (name-verbosity defaults, ensure-break defaults, debug-draw toggles). Reach this class via `GetDefault<UCk_Core_Settings>()`.

**Key files:** `CkCore_Settings.h`

For the full use-case table and how this folder fits with the rest of CkCore, see [`../../Claude.md`](../../Claude.md).
