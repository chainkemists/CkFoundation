# CkCore / StructTypeSelector

`FCk_StructTypeSelector` — typed dispatch helper for picking a concrete struct from a family at runtime. Used when content authors need to select "which variant of X" from a dropdown and the selected struct is then consumed polymorphically.

**Key files:** `CkStructTypeSelector.h`

For the full use-case table and how this folder fits with the rest of CkCore, see [`../../Claude.md`](../../Claude.md).
