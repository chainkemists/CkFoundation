# CkCore / Object

`UCk_WorldContextObject` — a `UObject` base that stores and exposes its world context. `UCk_Utils_Object_UE` provides generic UObject helpers (safe outer-walk, type-name introspection).

**Key files:** `CkObject_Utils.h`, `CkWorldContextObject.h`

For the full use-case table and how this folder fits with the rest of CkCore, see [`../../Claude.md`](../../Claude.md).
