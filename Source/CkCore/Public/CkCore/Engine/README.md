# CkCore / Engine

Custom bases for engine singletons — `UCk_GameEngine`, `UCk_GameInstance`, `ACk_GameMode`, `ACk_GameState`. Wire these in your project's `DefaultEngine.ini` to get CkFoundation lifecycle hooks.

**Key files:** `CkGameEngine.h`, `CkGameInstance.h`, `CkGameMode.h`, `CkGameState.h`

For the full use-case table and how this folder fits with the rest of CkCore, see [`../../Claude.md`](../../Claude.md).
