# CkCore / AngelScript

Glue between CkFoundation and AngelScript — type-validation helpers for the AS generator, debugger entry points. All gated on `WITH_ANGELSCRIPT_CK`.

**Key files:** `CkAngelScript_TypeValidation.h`, `CkAngelscriptDebugger.h`

For the full use-case table and how this folder fits with the rest of CkCore, see [`../../Claude.md`](../../Claude.md).
