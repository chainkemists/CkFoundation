# CkCore / MessageDialog

Thin wrappers over UE's `FMessageDialog` — localized prompts, typed yes/no/cancel returns. Editor-leaning; runtime callers should prefer in-game UI.

**Key files:** `CkMessageDialog.h`, `CkMessageDialog_Utils.h`

For the full use-case table and how this folder fits with the rest of CkCore, see [`../../Claude.md`](../../Claude.md).
