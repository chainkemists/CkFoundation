# CkCore / TypeConverter

`CkTypeConverter` — templated conversion helpers between related types (e.g., `FCk_Time` ↔ `FCk_Time_Unreal`). Keeps ad-hoc `static_cast` chains off call sites.

**Key files:** `CkTypeConverter.h`

For the full use-case table and how this folder fits with the rest of CkCore, see [`../../Claude.md`](../../Claude.md).
