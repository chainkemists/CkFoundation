# CkBuildConfig

**Build configuration only — no C++ classes.** Contains compile-time flag headers (`CK_DISABLE_ENSURE_CHECKS`, `CK_DISABLE_ENSURE_DEBUGGING`, and similar). Referenced by `CkCore/Build/CkBuild_Macros.h`.

**Depends on:** nothing. **Used by:** `CkCore`, `CkLog`.

See `CkCore/Build/README.md` for how these flags gate the Ensure system.
