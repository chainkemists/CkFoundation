# CkEditorStyle

**Editor infrastructure module.** Shared icon/color/font styles for all CkFoundation editor UIs. Access via `FCk_EditorStyle::GetStyleSet()`. Add new icons here; don't embed raw brushes in individual editor modules.

**Depends on:** `CkCore`, `CkSettings`.

For context, see [`/Source/EDITOR_MODULES.md`](/Source/EDITOR_MODULES.md).
